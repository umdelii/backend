리눅스 명령어
ls(list) : 파일 나열
ls -l : 상세 나열
ls -al : .으로 시작하는 파일까지 보여주기

	rwxr-xr-x 22 root root 4096 Mar  3 10:03 ..
	rw-------  1 root root   57 Mar  3 10:39 .Xauthority

man ls : manual ls(ls 명령어 매뉴얼)

pwd : 현재 위치
mkdir 디렉토리명 : 새로운 폴더 생성
cd 디렉토리명 : 해당 디렉토리로 이동

파일 생성
touch abc.txt : abc 텍스트파일 생성(내용x)

편집기 사용
vim 파일명
	i(insert) => 작성 => esc => :wq(write&quit)
nano 파일명
	문서작성 => write out(ctrl + o) => 파일명확인(enter) => exit
echo "파일에 작성할 내용" > test.txt
> : 덮어쓰기 / >> :append

cat 파일명 : 파일 미리보기

cp 원본파일명 복사할파일명 : 파일 복사
rm 파일명 : 파일 삭제

rmdir 디렉토리명 : 디렉토리 삭제
rm -r 디렉토리명 : 디렉토리(비어있지않은) 강제 삭제

심볼릭 링크 ( == 원도우즈 바로가기)
ln -s 원본파일명 바로가기파일명 : 심볼릭 링크

find : 파일과 디렉토리 검색
find . -name 파일명 : 현재폴더부터 하위폴더까지 파일명과 해당하는 파일 찾기
find . -type f -iname \*.mp4 : 현~하위폴더까지 대소문자 구분없이(-iname) 타입이 파일인 것 중 확장자가 mp4인 파일찾기
find . -type f -newermt 20260303 : 지정된 날짜 이후에 수정된 파일 찾기
-type f(파일) d(디렉토리) l(심볼릭링크)

grep 찾을문자열 파일명 : 해당 파일에서 문자열 검색
grep -r 찾을문자열 : 현재~하위 폴더에서 해당문자열 찾기 

adduser 사용자명 : 일반사용자 생성
deluser --remove-home 사용자명 : 삭제 , 해당 유저의 디렉포함

cat /etc/passwd : 리눅스 시스템에 등록된 사용자 계정 정보 조회

whoami : 현재 사용자 확인
id : id 확인
su - 사용자명 : 사용자 전환
chmod : 권한 설정
chmod 777 파일명  or 폴더명 : 새롭게 권한 지정
chmod a+w 파일명 : 해당파일에 write 권한 추가

sudo : super user do => 일반 사용자는 사용 불가
usermod -aG sudo 사용자명 : sudo 사용할 수 있도록 권한부여
