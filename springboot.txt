스프링부트 동작방식
1. DispatcherServlet : 웹 요청을 처음에 받음
2. 요청 경로 파악 후 HandlerMapping, HandlerAdapter 객체 사용
3. 적절한 컨트롤러로 요청 넘김
4. 컨트롤러 동작 후 결과를 템플릿과 함께 리턴
5. 클라이언트 화면에 출력

템플릿규칙
void : http://localhost:8080/home 요청 시 사용했던 경로에서 마지막에 존재하는 경로에 .html을 붙여서 찾기

void : http://localhost:8080/content/home -> content/home.html
    ex. http://localhost:8080/board/add -> board/add.html

String : return 값에 html을 붙여서 찾기

컨트롤러
@Controller 어노테이션을 붙이면 : 해당 클래스가 컨트롤러 역할임을 명시
    - 프레임워크가 해당 클래스를 관리(new 하겠다. 객체생성하겠다.)
    - 경로 중복 금지!!

에러 status 
500 = 서버쪽 에러 
 1. TemplateInputException : html 없어서 오류
404 = 경로없음
 1. 컨트롤러 경로 확인
403 = 권한 없음(security문제)
405 = 매핑이 잘못되어있음(get,push,put,delete 확인)

 http://localhost:8080 -> 컨트롤러 찾기 -> 컨트롤러 코드 실행 -> template 작업 -> template 화면 보기

 http://localhost:8080/board/read?no=1 - ?뒤는 파라메터(매개변수)


 @RequestParam = http 요청의 파라미터를 컨트롤러 메소드의 매개변수로 바인딩(연길)
    public void postCalc(int num1,int num2){}: 이름 똑같이 한다면 @RequestParam 없이도 가능
    public void postCalc(@RequestParam int num1,@RequestParam int num2){}:
    public void postCalc(@RequestParam("num1") int number1,@RequestParam int num2){}: 매개변수 이름이랑 다를때
    public void postCalc(@RequestParam(required = false, defaultValue = "0") int num1,@RequestParam(required = false, defaultValue = "0") int num2){}: 
        required -> 값이 안들어올수도있음, defaultValue -> 디폴트 값

Model : 스프링프레임워크가 제공해줌
 하는 일 : 컨트롤러가 뷰(사용자가 보는 화면)에 데이터를 전달하기 위해 사용하는 인터페이스
 model.addAttribute("key",value) , key 값은 중복 안되게

@ModelAttribute("키") : Model 객체와 하는 일이 똑같음
Model : 뷰로 데이터 전달
@ModelAttribute("키") : 뷰로 데이터 전달 + (데이터 바인딩)

HttpSession : 컨트롤러가 뷰에 데이터를 전달하기 위해 사용
Model과 다르게 redirect 이동 시에도 사용가능

RedirectAttributes : 리다이렉트가 발생한 후 데이터를 일회성으로 전달하기 위해 사용하는 인터페이스
 1. 주소줄 이용 : rttr.addAttribute()
 2. HTTP session을 임시로 사용 : rttr.addFlashAttribute()

thymeleaf
${} : 객체 or 변수값 표현
@{} : link 표현
${#} : 형식 지정 (ex.날짜표시)
${#temporals.format(객체변수명.지역변수명, 'yyyy-MM-dd HH:mm')} << thymeleaf에서 만들어준 java.time 날짜 객체 형식 변환법

th:text : 일반 태그용
th:value : form 태그용
th:each="객체변수명,상태변수명 : ${컨트롤러에서 사용한 배열 이름}" : 반복문
    상태변수를 통해 index,count,size,odd,even 등 배열의 value가 아닌 정보들도 추출가능
th:info : 조건문 => else 없음
th:unless : 얘가 else
th:switch : 스위치문
 th:case : case도 같이
<a th:href="@{컨트롤러경로}"> : 링크
<a href="/new?no=1"> == <a th:href="@{/new(no=1)}">
<script th:scr="@{/js/my.js}" : script 폴더 아래 경로없음 
<link th:href="@{/css/my.css}" rel="stylesheet"> : css 경로없음
<img th:src=@{/img/my.jpg}"> : 이미지 파일
th:object="${dto명(예:bookDTO)}" 
	- 맨앞글자는 소문자로, 
	  만약 이름을 바꾸고 싶은 경우에는 controller 매개변수에 @ModelAttribute("html에 명시할 이름")을 붙이자
th:classappend : class=" " 안의 내용 추가

<div class="text-danger" th:if="${#fields.hasErrors('title')}" th:errors="*{title}"></div>


thymeleaf-layout-dialect
layout.html : 전체 레이아웃 정의
 변경되지 않는 디자인 작성
 변경되는 부분은
  thymeleaf 기본방식
  <div th:replace="파일경로::바꿀태그이름"> : 이 태그를 대체하면서 디자인 영역이 적용됨 
  <div th:insert=""> : 이 태그 사이에 디자인 영역이 적용됨

유효성 검사
 사용자 입력값 검증
 why? DB에 저장되는 값이기에 무결해야함
 1. front => javascript
 2. back => spring validation
    @NotEmpty
    @NotBlank
    @Length(min=3,max=7)
    @Email
    @Max(숫자), @Min()
    @NotNull
    @size
    @Pattern(정규식)

@Pattern 정규식
    ex. 아이디는 영어대문자 하나 포함, 숫자가능, 특수문자는 #$%만 허용해서 5~12자 사이
